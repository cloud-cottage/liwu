# 品牌方后台页面规范

## 概述
品牌方后台是面向品牌方角色的管理后台，负责品牌商品管理和订单处理。

**所属范围**：管理后台（Partner Dashboard）
**上级规范**：[`partner.spec.md`](./partner.spec.md)

## 角色权限
- 权限范围限于所属品牌
- 可管理品牌商品、SKU、库存
- 可处理品牌相关订单
- 不可查看其他品牌数据
- 不可进行全局系统配置

## 功能模块
品牌方后台包含以下功能模块（具体以实际权限为准）：

| 模块 | 说明 |
|------|------|
| 总览 | 品牌数据概览、销售统计 |
| 工坊 | 商品管理、SKU 管理、库存管理 |
| 订单 | 订单处理、发货管理 |
| 设置 | 品牌资料设置、店铺设置 |

## 页面结构
- 左侧：侧边栏导航
- 右侧：主内容区域

## 相关组件
- 主入口：`apps/web/src/pages/Partner.jsx`
- 根据角色权限动态显示功能模块
- 品牌相关组件：`ShopManagement.jsx` 等

## 权限控制
- 通过用户标签（tags）判断品牌方角色
- 品牌负责人标签：`brand_lead`
- 品牌成员标签：`brand_member`
- 功能模块根据角色权限动态渲染
- 数据范围限定为所属品牌
