# 代理商后台页面规范

## 概述
代理商后台是面向代理商角色的管理后台，负责旗下店铺和用户的运营管理。

**所属范围**：管理后台（Partner Dashboard）
**上级规范**：[`partner.spec.md`](./partner.spec.md)

## 角色权限
- 权限范围限于所管理的代理商区域
- 可查看和管理旗下店铺和用户
- 可进行店铺运营相关操作
- 不可进行全局系统配置

## 功能模块
代理商后台包含以下功能模块（具体以实际权限为准）：

| 模块 | 说明 |
|------|------|
| 总览 | 代理商区域数据概览 |
| 用户 | 旗下用户管理 |
| 工坊 | 旗下店铺管理、商品管理 |
| 福豆 | 福豆结算、调账申请 |
| 冥想 | 冥想内容查看 |
| 觉察 | 觉察内容查看 |
| 设置 | 店铺设置、基础配置 |

## 页面结构
- 左侧：侧边栏导航
- 右侧：主内容区域

## 相关组件
- 主入口：`apps/web/src/pages/Partner.jsx`
- 根据角色权限动态显示功能模块

## 权限控制
- 通过用户标签（tags）判断角色
- 代理商标签：`partner_agent` 或类似标识
- 功能模块根据角色权限动态渲染
