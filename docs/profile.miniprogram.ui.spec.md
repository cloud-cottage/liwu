## 1. 全局页面壳层

所有个人相关页面使用 `.page-shell` 作为外层容器。

### 1.1 页面背景

```css
background: linear-gradient(180deg, #f3f0ea 0%, #f8f5ef 100%);
color: #1f2937;
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif;
```

### 1.2 装饰层（`::before` 伪元素）

固定铺满视口，三层叠加：

1. 左上鼠尾草绿光晕：`radial-gradient(circle at 16% 14%, rgba(143,165,138,0.14) …)`
2. 右上米色光晕：`radial-gradient(circle at 82% 16%, rgba(214,206,190,0.18) …)`
3. 斜向细纹：`repeating-linear-gradient(135deg, … rgba(143,165,138,0.05) …)`

不透明度 `0.84`，`pointer-events: none`。

### 1.3 内边距与安全区

- 水平/顶部内边距：`28rpx`
- 底部内边距：`calc(env(safe-area-inset-bottom) + 126rpx)`（为自定义 TabBar 留空）
- 个人页额外底部间距：`44rpx`（`.profile-page-shell` 等）

### 1.4 通用卡片 `.section-card`

| 属性 | 值 |
|---|---|
| 背景 | `rgba(255,255,255,0.9)` |
| 圆角 | `20rpx` |
| 内边距 | `28rpx` |
| 阴影 | `0 14rpx 34rpx rgba(15,23,42,0.06)` |
| 边框 | `1rpx solid rgba(143,165,138,0.12)` |
| 毛玻璃 | `backdrop-filter: blur(12rpx)` |

### 1.5 通用按钮

**主按钮 `.primary-button`**

- 背景：`linear-gradient(135deg, #8fa58a, #a7b69a)`
- 文字：`#ffffff`，`28rpx`，字重 `600`
- 高度：最小 `88rpx`，圆角 `999rpx`
- 阴影：`0 16rpx 30rpx rgba(143,165,138,0.24)`

**次要按钮 `.ghost-button`**

- 背景：`rgba(255,255,255,0.92)`
- 文字：`#4d5a4b`，`26rpx`，字重 `600`
- 边框：`1rpx solid rgba(143,165,138,0.18)`
- 高度：最小 `84rpx`，圆角 `999rpx`

**状态芯片 `.status-chip`**

- 背景：`rgba(143,165,138,0.12)`
- 文字：`#4d5a4b`，`22rpx`，字重 `600`
- 圆角：`999rpx`，内边距 `10rpx 16rpx`

### 1.6 底部 TabBar（个人页激活态）

| 状态 | 颜色 |
|---|---|
| 默认标签文字 | `#6b7280` |
| 激活标签文字 | `#8b5e34` |

## 2. 我的（主页面）`pages/profile/index`

导航栏标题：**我的**

### 2.1 整体排布（自上而下）

```text
┌─────────────────────────────────────┐
│ 状态双卡网格（2 列）                  │

│  └──────────────┘ └──────────────┘  │
├─────────────────────────────────────┤
│ 个人资料卡                           │
│  [头像] 姓名/学员芯片/手机号芯片/简介   │
│         [工坊] [地址] 快捷工具（右列）  │
│  邀请码 | 觉察次数（2 列统计）        │
```

区块间距：`24rpx`。

### 2.2 状态双卡 `.profile-status-grid`

紧凑型双卡，刻意压低高度以减少首屏视野占比（覆盖 `.section-card` 默认 `28rpx` 内边距）。

- 布局：`grid`，两列等宽，间距 `12rpx`，区块下边距 `20rpx`
- 卡片最小高度：`112rpx`
- 卡片内边距：`16rpx 20rpx`（覆盖通用卡 `28rpx`）
- 背景：`linear-gradient(180deg, rgba(255,255,255,0.98), rgba(248,245,239,0.94))`
- 标题 `.status-card-title`：`20rpx`，字重 `700`，颜色 `#7c6855`，字间距 `0.04em`
- 数值 `.status-card-value`：`28rpx`，行高 `1.25`，上边距 `8rpx`，字重 `700`，颜色 `#111827`
- 辅助 `.status-card-meta`：`20rpx`，上边距 `4rpx`，颜色 `#6b7280`

**交互**：左侧「花开纪念册」卡片点击跳转 `pages/profile/album/index`。

### 2.3 个人资料卡 `.profile-card`

**顶部行 `.profile-card-top`**：横向 flex，左资料区 + 右工具区。

**头像 `.profile-avatar`**

- 尺寸：`104rpx × 104rpx`，正圆
- 背景：`linear-gradient(135deg, #8fa58a, #a7b69a)`
- 文字：首字（默认「悟」），`42rpx`，`#ffffff`，字重 `700`
- 点击跳转 `pages/profile/info/index`

**姓名行**

**右侧工具 `.profile-tools`**：纵向 grid，间距 `10rpx`。

**统计区 `.profile-stats`**：两列 grid，间距 `14rpx`，上边距 `22rpx`。

## 7. 交互行为摘要

| 操作 | 行为 |
|---|---|
| 下拉刷新 | 主页面 `onPullDownRefresh` 重新加载资料 |
| 点击头像 | 进入个人信息页 |
| 点击花开纪念册卡 | 进入纪念册页 |
| 编辑区折叠 | 默认收起，减少首屏表单干扰 |
| 手机号 | 须通过微信授权绑定，保存前校验 `1\d{10}` |
| 纪念册徽章 | 点击打开弹层；已获得方可佩戴/取消佩戴 |
