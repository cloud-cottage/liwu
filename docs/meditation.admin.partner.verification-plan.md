## 0.1 验收方法论硬要求（R14，第一批验收裁定 2026-09-24）

> 以下四条由第一批验收踩坑后固化，**第二批起逐条强制**；违反任一条所得结论**无效**（既可能把环境伪失败记成缺陷，也可能漏掉真实缺陷）。
