# 管理后台总规范

## 概述
管理后台（Partner Dashboard）是礼物社区的运营管理平台，用于社区运营、内容管理、用户管理、店铺管理等后台操作。

## 角色体系
管理后台支持三种角色，不同角色拥有不同的权限和功能范围：

### 1. 管理员（Admin）
- 最高权限，可访问所有功能模块
- 负责全局配置、系统设置、用户管理
- 对应文档：`admin.partner.spec.md`

### 2. 代理商（Agent）
- 负责旗下店铺和用户的运营管理
- 权限范围限于所管理的代理商区域
- 对应文档：`agent.partner.spec.md`

### 3. 品牌方（Brand）
- 负责品牌商品管理、订单处理
- 权限范围限于所属品牌
- 对应文档：`brand.partner.spec.md`

## 功能模块
管理后台侧边栏包含以下功能模块：

| 模块 | 说明 |
|------|------|
| 总览 | 数据概览、关键指标 |
| 用户 | 用户列表、用户管理、标签管理 |
| 工坊 | 商品管理、订单管理、店铺设置 |
| 福豆 | 福豆管理、调账、结算 |
| 冥想 | 冥想内容管理、冥想设置 |
| 觉察 | 觉察标签管理、觉察内容设置 |
| 设置 | 主题设置、页面配置、系统参数 |
| 人工智能 | AI 相关配置 |
| 版本 | 客户端版本管理、分发设置 |

## 技术架构
- 前端：React + Vite
- 后端：CloudBase 云开发
- 数据库：云数据库
- 文件存储：云存储

## 访问地址
- 本地开发：`http://127.0.0.1:5175/admin`
- 生产环境：根据部署配置而定
